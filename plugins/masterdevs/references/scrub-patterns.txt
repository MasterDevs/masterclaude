# Scrub patterns — pattern CLASSES only, one POSIX extended regex per line.
#
# Read by /masterdevs:contribute for the upstream path only. Two jobs, same list:
#   1. rewrite  — replace each match in the temp clone's copy with a generic placeholder
#   2. gate     — after rewriting, re-read the scrubbed copies and REFUSE to push on any hit
#                 (the files, not the git index — nothing is staged when the gate runs)
# The rewrite is best-effort; the gate is the guarantee.
#
# This file holds only SHAPES. Your own organisation, repository and module names cannot ship in a
# public repo, so they live in your data dir instead:
#
#     $PLAYBOOK_DIR/scrub-patterns.local.txt
#
# ...which /masterdevs:contribute reads in addition to this file when it exists.
#
# Note on the key shapes below: the vendor prefixes are written with a bracketed letter
# (A[K]IA rather than AKIA). The regex still matches a real key, but the line itself no longer
# matches this repository's own leaked-identifier check — the same self-exclusion problem
# .github/workflows/ci.yml solves for itself.

# ── Absolute paths that name a person or a machine ────────────────────────────
/(Users|home)/[A-Za-z0-9_.-]+
[A-Za-z]:\\(Users|Documents and Settings)\\[A-Za-z0-9_.-]+
/(private/)?(var|tmp)/folders/[A-Za-z0-9_/+-]+

# ── Key- and token-shaped strings ─────────────────────────────────────────────
A[K]IA[0-9A-Z]{16}
A[S]IA[0-9A-Z]{16}
gh[pousr]_[A-Za-z0-9]{20,}
sk-[A-Za-z0-9_-]{20,}
xox[abposr]-[A-Za-z0-9-]{10,}
-----BEGIN [A-Z ]*PRIVATE KEY-----
eyJ[A-Za-z0-9_-]{10,}\.[A-Za-z0-9_-]{10,}\.[A-Za-z0-9_-]{10,}

# ── Issue-tracker ids: deliberately NOT here ──────────────────────────────────
# A tracker id has no shape of its own. `[A-Z]{2,6}-[0-9]+` also matches UTF-8, SHA-256, AES-256,
# ISO-8601, RFC-7231 and PEP-8 — the ordinary vocabulary of an entry explaining why some code is good.
# Since the gate REFUSES on any hit and offers no override, that class does not catch leaks so much as
# it blocks contributions. A tracker prefix is an organisation's own name, so it belongs in the local
# file with the rest of them:
#
#     $PLAYBOOK_DIR/scrub-patterns.local.txt
#     (ENG|PROJ|OPS)-[0-9]+
#
# /masterdevs:contribute asks about tracker ids when that file carries no such line.

# ── Internal network locations ────────────────────────────────────────────────
# The suffix has to END the hostname. Matched loosely, `.local` also hits `settings.local.json` and
# `state.local.ts` — filenames, in a lane full of filenames.
[A-Za-z0-9-]+(\.[A-Za-z0-9-]+)*\.(internal|local|corp|intranet|lan)([^A-Za-z0-9.-]|$)
(postgres|postgresql|mysql|mongodb|redis|amqp)://[^[:space:]"']+
[A-Za-z0-9-]+\.[a-z0-9-]+\.rds\.amazonaws\.com
(10|127)\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}
192\.168\.[0-9]{1,3}\.[0-9]{1,3}

# ── Contact details ───────────────────────────────────────────────────────────
[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}
